SVG (and optional PNG) files in this directory are generated by the
[render-md-mermaid](https://github.com/marketplace/actions/render-md-mermaid)
workflow when tracked `.md` files change, or locally with `scripts/ops/render-docs-mermaid.sh`
(Docker required). Do not edit SVGs by hand.

The markup must match **render-md-mermaid v3**: an image line targeting an SVG
under `docs/images/`,
then a `<details>` block (with a ` ```mermaid ` fence), so the action can find each
diagram. Edit the Mermaid source inside those `<details>` sections in the Markdown files.

| SVG | Used in |
|-----|---------|
| `readme-architecture-overview.svg` | `README.md` |
| `readme-architecture.svg` | `docs/architecture.md` |
| `readme-data-flow.svg` | `docs/architecture.md` |
| `readme-ci-cd.svg` | `docs/operations.md` |
